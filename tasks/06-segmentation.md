# משימה 06: חלוקה לקטעים (Segmentation)

**סוג:** ליבה (חובה) · **מומלץ:** יחיד או זוג

## מטרת למידה
פירוק הקלטה ארוכה לקטעים לפי מי מדבר מתי - חיבור בין הקלטה שלמה לזיהוי הבודד ממשימה 05.

## קלט → פלט (לפי חוזה ה-API)
`POST /identify` — קלט: `{"file_url": "..."}`
פלט:
```json
{
  "segments": [
    {"start": 0.0, "end": 12.4, "speaker": "speaker_A", "confidence": 0.87},
    {"start": 12.4, "end": 30.1, "speaker": "unknown", "confidence": 0.31}
  ]
}
```

## ספריות מומלצות
`librosa` או `pydub` (לחיתוך לחלונות זמן), + פונקציית הזיהוי ממשימה 05

## קריטריון סיום (Definition of Done)
- [ ] הקלטה ארוכה (עם 2+ דוברים) מתחלקת לרשימת segments עם start/end נכונים
- [ ] ה-JSON המוחזר תואם בדיוק לחוזה (שמות שדות, מבנה)
- [ ] סכום ה-segments מכסה את כל אורך ההקלטה (אין "חורים" בציר הזמן)
- [ ] הקלטה עם דובר יחיד לאורך כולה מחזירה segment יחיד
- [ ] גודל חלון החיתוך (למשל כל 3-5 שניות) מתועד וברור בקוד

## טיפים
- הגישה הפשוטה ביותר: לחתוך את ההקלטה לחלונות קבועים (למשל כל 3 שניות), להריץ זיהוי על כל חלון בנפרד, ואז "לאחות" חלונות עוקבים עם אותו דובר לסגמנט אחד.
- זו נקודת החיבור הישירה בין משימה 05 (זיהוי בודד) לכל שאר המערכת - תאמו ממשק פנימי עם מי שעושה משימה 05.
