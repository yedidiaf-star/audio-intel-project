# משימה 11 (בונוס): סיכום נרטיבי בשפה טבעית (LLM מקומי)

**סוג:** בונוס · **מומלץ:** יחיד · **תלוי ב:** משימה 06/09 (segments + אופציונלי תמלול)

## מטרת למידה
שימוש ב-LLM מקומי (לא API בתשלום) ליצירת סיכום קריא של תיק שלם - כתיבת prompt מונחה-משימה ועיבוד פלט מודל שפה.

## קלט → פלט
קלט: JSON של segments (+ טקסט מתומלל אם קיים ממשימה 09)
פלט: `{"summary": "פסקת טקסט בעברית..."}`

## ספריות מומלצות
`Ollama` (מודל כמו `llama3` או `phi3` שרץ מקומית - **לא** קריאה ל-API חיצוני בתשלום)

## קריטריון סיום (Definition of Done)
- [ ] המודל רץ מקומית ולא שולח מידע לשירות חיצוני
- [ ] הסיכום המופק מזכיר מספר דוברים ואת חלוקת הזמן ביניהם (על בסיס הנתונים בפועל, לא "המצאה")
- [ ] אם אין מספיק נתונים (למשל segment יחיד קצר) - הסיכום עדיין הגיוני ולא מוזר
- [ ] הסיכום מוטמע בפועל בדוח ממשימה 07

## טיפים
- זו הזדמנות טובה ללמד prompt engineering בסיסי: לתת למודל את הנתונים המובנים (לא רק "תסכם"), ולבקש ממנו במפורש להתבסס רק על מה שסופק.
- להדגיש לתלמידים: מודל שפה יכול "להמציא" פרטים (hallucination) - חשוב לבדוק שהסיכום תואם בפועל למספרים ב-JSON.
