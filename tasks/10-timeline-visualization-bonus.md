# משימה 10 (בונוס): ציר זמן ויזואלי

**סוג:** בונוס · **מומלץ:** יחיד · **תלוי ב:** משימה 06 (segmentation) + 07 (דוח)

## מטרת למידה
המרת נתוני JSON לגרף - חיבור בין מבנה נתונים (segments) לייצוג חזותי (Gantt-style timeline).

## קלט → פלט
קלט: אותו JSON של segments ממשימה 06
פלט: תמונה (PNG) או HTML אינטראקטיבי שמוטמע בדוח של משימה 07

## ספריות מומלצות
`matplotlib` (לגרף סטטי) או `Chart.js` (ל-HTML אינטראקטיבי)

## קריטריון סיום (Definition of Done)
- [ ] כל דובר מקבל שורה/צבע קבוע משלו בגרף
- [ ] מיקום ואורך כל קטע בגרף תואמים ל-`start`/`end` בנתונים
- [ ] קטעי `unknown` מסומנים בצורה שונה/מובחנת (למשל צבע אפור)
- [ ] הגרף כולל ציר X עם יחידות זמן ברורות (שניות/דקות)
- [ ] הגרף/רכיב מוטמע בפועל בתוך הדוח ממשימה 07, לא קובץ נפרד ומנותק

## טיפים
```python
speaker_row = {name: i for i, name in enumerate(speakers)}
ax.barh(speaker_row[seg["speaker"]], seg["end"] - seg["start"],
        left=seg["start"], alpha=seg["confidence"])
```
