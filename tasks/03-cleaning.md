# משימה 03: ניקוי אודיו (חיתוך שקטים + נרמול)

**סוג:** ליבה (חובה) · **מומלץ:** יחיד או זוג

## מטרת למידה
עיבוד אות שמע בסיסי: זיהוי והסרת קטעי שקט, נרמול עוצמה, והמרה לפורמט אחיד שיתאים לכל שאר המערכת.

## קלט → פלט (לפי חוזה ה-API)
`POST /clean` — קלט: `file_id` (מהמשימה הקודמת) או קובץ ישירות
פלט:
```json
{
  "duration_sec": 42.3,
  "sample_rate": 16000,
  "silence_trimmed_sec": 8.1,
  "file_url": "/files/cleaned_001.wav"
}
```
קובץ הפלט **חייב** להיות WAV, 16kHz, mono — זה מה שכל שאר המערכת מצפה לקבל.

## ספריות מומלצות
`pydub`, `numpy`

## קריטריון סיום (Definition of Done)
- [ ] קובץ עם שקטים ארוכים בהתחלה/סוף — השקטים נחתכים
- [ ] קובץ פלט הוא תמיד 16kHz mono, גם אם הקלט היה בפורמט אחר (44.1kHz stereo וכו')
- [ ] עוצמת הקול מנורמלת (קובץ חלש מוגבר, קובץ חזק מדי מוחלש)
- [ ] ה-JSON המוחזר תואם בדיוק למבנה בחוזה (כולל שמות שדות)
- [ ] קובץ קצר מאוד (פחות משנייה) או קובץ שכולו שקט — מטופל בלי קריסה

## טיפים
```python
audio = AudioSegment.from_file(input_path)
audio = audio.set_frame_rate(16000).set_channels(1)
```
זו נקודת ההתחלה להמרה - חיתוך השקטים ונרמול העוצמה דורשים עוד קצת עבודה מעבר לזה.
