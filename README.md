# תיק מבצע — זיהוי קול מודיעיני

פרויקט לימודי: אתר לסוכנים שמעלים הקלטות שמע, המערכת מנקה אותן, מזהה מי מדבר, ומפיקה דוח מודיעיני.

## מבנה הפרויקט

```
audio-intel-project/
├── README.md              קובץ זה
├── .gitignore
├── requirements.txt        כל הספריות של כל המשימות - pip install -r requirements.txt
├── docs/
│   ├── student-setup.md   מדריך הורדה והתקנה — כאן מתחילים!
│   ├── api-contract.md    חוזה ה-API הקבוע בין חלקי המערכת — קרא/י לפני שמתחילים!
│   └── git-workflow.md    פרוטוקול עבודה ב-Git — קרא/י לפני ה-commit הראשון!
├── tasks/                 כרטיס משימה לכל תלמיד/זוג
│   ├── 01-...  עד  07-...   משימות ליבה (חובה)
│   └── 08-...  עד  12-...   משימות בונוס
├── server/                כאן ייכתב הקוד שלכם - ראו docs/api-contract.md לאיזה קובץ שייך לאיזו משימה
│   ├── app.py             routes בלבד - קורא לפונקציות מתוך tasks/
│   ├── templates/
│   └── tasks/             קובץ נפרד לכל משימה (task_01_login.py וכו')
└── data/                  קבצי שמע לדוגמה + מאגר קולות
```

## איך להתחיל
1. קרא/י את `docs/student-setup.md` — הורדת הפרויקט והתקנה על המחשב שלך.
2. קרא/י את `docs/git-workflow.md` — כך עובדים על הקוד בפרויקט הזה (branch, PR, review).
3. קרא/י את `docs/api-contract.md` — זה הבסיס שכל המשימות בנויות עליו.
4. מצא/י את כרטיס המשימה שלך תחת `tasks/`.
5. כל כרטיס משימה כולל: מטרת למידה, קלט/פלט מדויק, ספריות מומלצות, וקריטריון סיום ברור.
6. משימות 01–07 הן ליבת המערכת (חובה). משימות 08–12 הן בונוס — מרחיבות פיצ'ר קיים או מוסיפות יכולת חדשה.
7. **כלל ברזל:** אם המשימה שלך משנה קלט/פלט מוגדר בחוזה — תאם/י עם מי שתלוי בך *לפני* שמשנים, לא אחרי.
